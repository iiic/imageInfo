Welcome to Image Info — a Firefox extension that lists all images of the page you are on with everything that can be found out about them: where the page uses them, how they loaded, their HTTP response headers and the metadata of their files (EXIF with the camera and GPS position, XMP, IPTC, the ICC color profile). The metadata is read from what the browser already has, so the images are not downloaded again.

Image Info

Thank you for using this extension. Take a look at the extension settings, where you can adjust more options than just the language.

Getting Started

Step 1: Grant the permissions

The extension needs them to work. The box at the top of this page shows what Image Info records. Click Grant the permissions there (the same box is in Settings) and allow:

  • access to all websites — to list the images of a page and read their files from the browser cache,
  • webRequest — to record the HTTP headers of images while pages load them.

Images loaded before that have no recorded headers — reload the page. Firefox keeps recording the headers only until its background page goes to sleep; after the next restart of the browser it records them permanently.

Step 2: Open the listing

  • Click the extension button in the toolbar — the popup lists the images of the current page.
  • For more room, open the sidebar: Firefox menu → View → Sidebar → Image Info. The sidebar stays next to the page.

The listing lists the page when it is shown; the Refresh button lists it again, for example after you scroll to images that load lazily. To let the sidebar follow another tab or a new address by itself, choose a "Start automatically" activation mode of Image Info Sandbox in Settings.

What the Listing Shows

Each image has a line with its name, size and badges. Its details show:

  • On the page — every place the page uses it: <img> and <picture>, CSS backgrounds, icons, video posters, images in SVG, preloads; the rendered and the natural size, whether it is hidden or outside the visible area, and its text alternative.
  • Loading — the status, from the cache or not, protocol, IP address, loading time, transferred and decoded size, redirects.
  • HTTP headers — the response headers as the browser received them (Content-Type, Content-Length, Last-Modified, Cache-Control, …).
  • Metadata — the format and its structure, dimensions, colors, JPEG quality, animation frames, the color profile, and from EXIF, XMP and IPTC the camera, lens, date of the shot, GPS position (with a link to a map), author, copyright, title, description and software.

Badges point out what is worth a look: a tracking pixel, mixed content (an image over http on an https page), an oversized image or a large file, an <img> without width and height, an image without a text alternative, a file type that does not match its Content-Type header, a serial number of the camera or lens, a thumbnail embedded in the file (it may show the photo before a crop).

The toolbar of the listing

  • Search and Order — as on the page, largest first, by name, by format.
  • Ignore small images — leaves out tracking pixels, spacers and small icons (the size is set in Settings).
  • Hide images not on the page — images the page only loaded (the tab icon, an image loaded by a script).
  • Clean dynamically — when a web app changes its address without loading a new page, the images from before are left out.
  • Only important — only the images with an important badge.

Buttons of an image

  • Save image — saves the file the browser already has; Download when it has to be downloaded again.
  • Load information — when headers or metadata are missing, downloads the image once more (optionally anonymously, without cookies).
  • Thumbnail — downloads the image once more and shows it in the listing.
  • Remove from the document — removes the image from the page in the tab until the page is reloaded.
  • Record permanently — keeps what the listing knows about the image in the extension, also after the tab is closed and the browser restarts.

Permanent Records and Serial Numbers

The section Permanently recorded images at the top of the listing keeps the records — on any page. By default an image whose metadata contains the serial number of the camera or of the lens is recorded by itself. When another page shows a photo with a serial number you have already recorded, the image gets the badge S/N match and its details list the matching records: the photos were most likely taken with the same device. A notification about such a match can be turned on in Settings.

Notices About Images

In Settings, the table of notices says for every property (a GPS position, a known camera, a tracking pixel, mixed content, …) what the listing does with an image that has it: show a badge, mark it important (never hidden), send a notification, record it permanently, or show the badge over the image on the page itself. Notifications and badges on the page work while the listing is open, for example in the sidebar.

Images From Other Origins

The metadata of an image comes from the browser cache, and only a file of the page's own origin can be read from there. In Firefox, turn on Read the metadata of images of other origins while they load in Settings: every image of every page then passes through the extension while it loads, so its metadata is known without downloading it again. It needs two more permissions (webRequestBlocking, webRequestFilterResponse) and applies from the next load of a page.

Privacy

Your data stays on your device. The extension sends nothing anywhere. It reads what the browser already has; only the buttons Load information, Download and Thumbnail download an image once more — from the server the page loaded it from. The map link of a GPS position opens OpenStreetMap only when you click it.
